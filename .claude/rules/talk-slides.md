# Talk slide style

- One idea per slide in revealjs talk decks: median about 5 words per slide, rarely over 30, with many `---` breaks (existing talks run 40–70 per deck). Check an existing talk's density before drafting, and render to PDF to inspect pages. Does not apply to `ws_*` workshop material.
- Style guide for these decks: see `TALK_STYLE.md` at the repo root.
